# AI Coding Harness

개인 개발 생산성을 높이기 위한 AI Coding Harness를 구축하는 프로젝트.

## Goal

AI를 단순한 코드 생성 도구가 아니라
설계, 구현, 검증, 리뷰를 수행하는 개발 시스템으로 활용한다.

목표:

- 개발 시간 단축
- 코드 품질 향상
- 성능 개선
- human intervention 감소
- 반복 작업 자동화
- 검증 가능한 AI 개발 workflow 구축
